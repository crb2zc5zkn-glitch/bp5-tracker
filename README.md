# Big Picture 5-Day

Personal 12-week training log (installable web app): plan sessions, log sets with RPE, track progress and weekly sets per muscle.

- Data is stored in your own browser (localStorage). Use *Data → Backup* to move it between devices.
- Not indexed by search engines.
- Program structure based on a workbook by Aquilina Strength Training (© Aquilina Strength Training / Outrajes LLC). Personal use only; not affiliated.
